# Panchvaktra Human Welfare Foundation — Web Application

Official web application for **Panchvaktra Human Welfare Foundation** ("Selfless beyond Selflessness").

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally (Development)
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

## Features & Highlights
- **Full-stack SSR**: Built with TanStack Start (React 19) and Vite.
- **Independent & Stable**: Self-contained architecture with local static assets and zero external platform lock-in.
- **Accessible & Neutral**: Inclusive, dignified messaging across all pages.
- **Working Forms**: Functional Inquiry, Volunteer Application, and Donation Pledge handlers with real reference generation.
- **Branding**: Official Panchvaktra emblem and responsive institutional layout.
